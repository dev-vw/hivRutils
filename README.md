# Description
This is a repo developed by members of the PRIME-DUIT team to automate recurring analytic tasks and store documentation of frequently-needed dataframes (e.g. ISO codes for PEPFAR countries).

# Sample contents
+ dataframe for Naomi app API options
+ dataframe for PEPFAR countries, regions, and ISO codes
+ tidied UNAIDS Spectrum dataset
+ code for pulling slices of Naomi app data
